# love-site

A romantic static website for Tamveel that works as a responsive web page across mobile, tablet, and desktop devices.

## Run locally

Open `index.html` in a browser or run a local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publish for all devices on any network

This project is designed as a static site, which means it can be hosted anywhere with a public URL. GitHub Pages is the simplest option:

1. Push this repo to GitHub.
2. Open the repository in GitHub.
3. Go to Settings > Pages.
4. Select the branch to publish (for example `main`).
5. Save.

Your site will then be accessible through a public URL like:

```text
https://yourusername.github.io/love-site/
```

This will work on different Wi-Fi networks and across devices.
